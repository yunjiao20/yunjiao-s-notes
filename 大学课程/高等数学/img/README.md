# 图片命名规定

如此图片名：`s_1_1_1_2_例2.jpg`

使用python `s.split('_')`处理此文件名得到`['s', '1', '1', '1', '2', '例2']`
- `[0]`位`s`意思是高数上册，下册为`x`
- `[1]`位`1`意思是第一章，查看上册目录可知为`函数与极限`
- `[2]`位`1`意思是第一节，查看上册目录第一章可知第一节为`映射与函数`
- `[3]`位`1`意思是此节下的第一小节，查看目录可知为`一、映射(1)`
- `[4]`位`2`意思是页数，标志此图片对应的题目在第几页，这里是`第二页`
- `[5]`位`例2`的意思是题目，此图片在此页的题目
即`上下册_章_节_小节_页数_题目`



下面写一个python代码来解析图片名信息
```python
def file_name_exec(file_name: str) -> None:
    '''解析此目录下文件名的含义,并输出出来'''
    msg = file_name.split('.')[0]   # 抛弃后缀
    msg = msg.split('_')

    if len(msg) != 6:
        print(f'此名不合法，{msg}数量不正确')
        return
    if msg[0] not in 'sx' or len(msg[0]) != 1:
        print(f'第一个信息只能是"s"上册或"x"下册')
        return

    print(f'高数{"上" if msg[0] == "s" else "下"}册', end=' ')
    print(f'第{msg[1]}章', end=' ')
    print(f'第{msg[2]}节', end=' ')
    print(f'第{msg[3]}小节')
    print(f'第{msg[4]}页', end=' ')
    print(f'{msg[4]}')
```
