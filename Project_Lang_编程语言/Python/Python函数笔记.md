- `ord()` 输入一个长度为 1 的字符串（单个字符），返回它对应的 Unicode 码点整数（如： ord('A') == 65）[[PyJail#字符串过滤]]
- `chr()` 输入一个整数（Unicode 码点），返回对应的字符（如：chr(65) == 'A'）[[PyJail#字符串过滤]]

- `zip()` 把多个可迭代对象对应位置的元素打包成元组，并返回一个迭代器‌，默认以最短的序列长度为准。
    list(zip( 'abc', range(2) ))  ==  \[('a', 0), ('b', 1)\]
    dict(zip('ABC', \[1, 2, 3\]))  == {'A': 1, 'B': 2, 'C': 3}
