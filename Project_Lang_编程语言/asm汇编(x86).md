### 寄存器

在Linux调用约定下

#### 32 位

##### 通用寄存器（共8个，32位）

| 寄存器 | 用途                                    |
| :-: | :------------------------------------ |
| EAX | 累加器。最常见：存函数返回值、算术运算结果                 |
| EBX | 基址寄存器。常当数据指针用（PIC 代码里指向 GOT 表）        |
| ECX | 计数器。循环计数、字符串/移位操作                     |
| EDX | 数据寄存器。除法的高位余数、乘法高 32 位、I/O 端口地址       |
| ESI | 源索引（Source Index）。字符串/内存操作的源指针        |
| EDI | 目的索引（Destination Index）。字符串/内存操作的目的指针 |
| EBP | 栈基址指针。指向当前栈帧底部，访问局部变量靠它               |
| ESP | 栈指针。始终指向栈顶，push/pop 自动增减              |

其中 EAX/EBX/ECX/EDX 还能拆成 16 位（AX、BX、CX、DX）和 8 位（AH/AL 等）用；ESI/EDI/EBP/ESP 只能拆低 16 位。

##### 段寄存器（共6个，各16位）

| 寄存器 | 用途                                 |
|:---:| :-----------------------                |
| CS  | 代码段                                  |
| DS  | 数据段                                  |
| SS  | 栈段                                    |
| ES  | 附加段                                  |
| FS  | 附加段，Linux 常用于线程局部存储（TLS） |
| GS  | 附加段，同样常用于 TLS                  |

##### 指令指针寄存器

EIP：指令指针，存下一条要执行指令的地址。

##### 标志寄存器

EFLAGS：标志寄存器（ZF 零、CF 进位、SF 符号、OF 溢出等，用于条件跳转）。

##### 浮点/向量寄存器

-  ST(0)ST(7)：x87 FPU 浮点栈，8 个 80 位寄存器。
-  MM0MM7：MMX（复用浮点寄存器）。
-  XMM0XMM7：SSE 寄存器，128 位，做 SIMD 浮点/整数运算。



#### 64 位

##### 通用寄存器（共16个，64位）

| 寄存器 | 用途                                              |
|:------:|:--------------------------------------------------|
| RAX    | 累加器，存函数返回值                              |
| RBX    | 基址，被调用者保存（callee-saved）                |
| RCX    | 计数器，第 4 个函数参数                           |
| RDX    | 数据，第 3 个函数参数（也参与 128 位除/乘）       |
| RSI    | 源索引，第 2 个函数参数                           |
| RDI    | 目的索引，第 1 个函数参数                         |
| RBP    | 栈帧基址，被调用者保存                            |
| RSP    | 栈指针                                            |
| R8~R15 | 新增的 8 个通用寄存器，其中 R8/R9 是第 5、6 个参数|

64 位下这些寄存器还能拆低 32 位（EAX）、16 位（AX）、8 位（AL/AH 等）访问。

##### 段寄存器

CS、DS、SS、ES、FS、GS 仍存在，但 64 位模式下大部分段基址被忽略（扁平模型），只有 FS/GS 还实际用于 TLS。

##### 指令指针寄存器

RIP：指令指针。64 位模式支持 RIP 相对寻址，访问全局变量很方便。

##### 标志寄存器

RFLAGS：标志寄存器，64 位扩展版。

##### 浮点/向量寄存器

• ST(0)ST(7)、MM0MM7：仍在，但 MMX 基本废弃。
• XMM0XMM15：SSE 扩展到了 16 个（128 位）。
• YMM0YMM15：AVX（256 位）。
• ZMM0ZMM31：AVX-512（512 位，共 32 个）。

##### 系统寄存器（内核/调试用）

• CR0CR8：控制寄存器（分页、保护模式等）。
• DR0DR7：调试寄存器（硬件断点）。
• GDTR / LDTR / IDTR / TR：描述符表寄存器。
• MXCSR：SSE 控制/状态寄存器。



#### 调用约定速记（System V AMD64）

• 传参（前 6 个整数参数）：RDI, RSI, RDX, RCX, R8, R9
• 返回值：RAX（128 位时 RDX:RAX）
• 被调用者保存（callee 用完要恢复）：RBX, RBP, R12~R15
• 调用者保存（caller 自行备份）：RAX, RCX, RDX, RSI, RDI, R8~R11
32 位的 cdecl 就简单多了：参数全部从右往左压栈，返回值放 EAX，EBX/EBP/ESI/EDI 是 callee-saved。





### Intel汇编语法 与 AT&T汇编语法

1. 操作数顺序‌：Intel是“目标在前，源在后”（如`mov eax, ebx  ;（目标←源）`），AT&T相反是“源在前，目标在后”（如`movl %ebx, %eax  # （源→目标）`）
2. 寄存器前缀‌：Intel直接写 `eax`，AT&T必须加 % 写成 `%eax`
3. 立即数前缀‌：Intel直接写 `100`，AT&T加 $ 写成 `$100`。
4. 内存寻址‌：Intel用 `[base+index*scale+disp]`，AT&T用`disp(base,index,scale)`
5. 操作数大小‌：Intel用 `byte ptr/word ptr/dword ptr`，AT&T用指令后缀 `b/w/l/q`

| 差异点     | Intel语法                 | AT&T语法                 |
| ------- | ----------------------- | ---------------------- |
| 操作数顺序   | 目标在前，源在后                | 源在前，目标在后               |
| 寄存器写法   | eax                     | %eax                   |
| 立即数写法   | 100                     | $100                   |
| 内存寻址    | [eax+ebx*4+100]         | 100(%eax,%ebx,4)       |
| 8位操作    | byte ptr                | b 后缀（movb）             |
| 16位操作   | word ptr                | w 后缀（movw）             |
| 32位操作   | dword ptr               | l 后缀（movl）             |
| 64位操作   | qword ptr               | q 后缀（movq）             |
| 绝对跳转    | jmp eax                 | jmp *%eax              |
| 远跳转     | jmp far section:offset  | ljmp $section,$offset  |
| 远调用     | call far section:offset | lcall $section,$offset |
| 远返回     | ret far stack_adjust    | lret $stack_adjust     |
| 注释      | ;                       | #                      |
| 大小写     | 通常大写                    | 通常小写                   |
| 十六进制立即数 | 0x100 或 100h            | $0x100                 |
