## gcc 常用编译参数
---
```
gcc [选项] file.c
    -E  只预处理，不编译（生成 file.i）
    -S  编译成汇编 file.s ,不生成可执行程序
    -c  编译成目标文件，不链接（file.o）
    -o <file>  指定生成的文件名
    -g  生成调试信息（gdb使用）
    -static  静态链接
    -shared  生成共享库 .so
```

## 基本结构
```C
// myheader.h
# include <stdio.h>    // 包含头文件，printf函数在标准输入输出头文件stdio.h中

// 这是一条单行注释

/*
多行注释
>ᴗ<
*/

void hi(){        // void，返回值为空
    printf("hi!\n");
}
```

```C
// test.c
# include <stdio.h>       // 头文件包含
# include "myheader.h"    // 自定义头文件使用 "" 包含， .c 文件也可以

# define PI 3.1415926     // 宏定义，预处理阶段进行文本替换

int add(int a, int b);    // 函数声明

int main(){               // 主函数，C程序必须有一个main函数，作为程序入口

    int num1, num2, sum;  // 变量声明，创建三个int变量

    hi();                 // 函数 hi 在 myheader.h 中被定义，#include后可调用
    printf("Enter two integers: ");
    scanf("%d %d", &num1, &num2);

    sum = add(num1, num2);  // 函数调用 

    printf("Sum: %d\n", sum);

    return 0;             // return终止函数并返回值，约定主函数返回0表示成功执行
}

int add(int a, int b){    // 函数定义
    return a + b;
}
```

`gcc test.c -o test`或`gcc test.c myheader.h -o test`，即可编译出程序`test`

#### 字符常量和字符串字面量
这是一个易错点，字符常量由单引号引起，如`'A'`，是一个int值，可以参与运算（字符常量只能有一个字符，`'ab'`等在标准C中是不合法的）。字符串字面量由双引号引起，是一个指向char\[N] 字符数组首元素的指针，以`\0`结尾，如`"A"`实际上有 "A" 和 "\0" 两个字节，存储在只读数据段`.rodata`，内容不可修改。
#### 运算符
    算术运算符：+, -, *, /, %（其中 / 对整数做整除，% 取余数）
    关系运算符：==, !=, >, <, >=, <=（返回 1 表示真，0 表示假）
    逻辑运算符：&&（与）, ||（或）, !（非），支持短路求值
    位运算符：&（按位与）, |（按位或）, ^（按位异或）, ~（按位取反）, <<（左移）, >>（右移）
    赋值运算符：=, +=, -=, *=, /=, %=（复合赋值，如 a += b 等价于 a = a + b）
    自增/自减运算符：++（自增）, --（自减），分前缀（先运算再取值）和后缀（先取值再运算）两种形式
    其他运算符：sizeof（计算类型或变量字节大小）, ?:（三目运算符）, &（取地址）, *（解引用）, ->（指针访问成员）, .（直接访问成员）

#### void
void 类型指定没有可用的值。它通常用于以下三种情况下：

| 序号  | 类型与描述                                                                                                                |
| --- | -------------------------------------------------------------------------------------------------------------------- |
| 1   | **函数返回为空**  <br>C 中有各种函数都不返回值，或者您可以说它们返回空。不返回值的函数的返回类型为空。例如 **void exit (int status);**                              |
| 2   | **函数参数为空**  <br>C 中有各种函数不接受任何参数。不带参数的函数可以接受一个 void。例如 **int rand(void);**                                            |
| 3   | **指针指向 void**  <br>类型为 void * 的指针代表对象的地址，而不是类型。例如，内存分配函数 **void *malloc( size_t size );** 返回指向 void 的指针，可以转换为任何数据类型。 |

## 常量
---
常量是固定值，在程序执行期间不会改变，又叫做**字面量** [[#常量]]

常量使用`const`关键字或`#define`宏定义。可以是整型常量、浮点型常量、字符常量、枚举常量等
`const int MAX = 100;`
常量在定义时必须进行初始化，不能`const int MAX`
#### 整数常量
前缀`0`为八进制，`0x`和`0X`为十六进制，没有前缀默认为十进制
后缀可以是`U`和`L`(大小写均可，`u`无符号整数，`l`长整数)
`072`、`0xff`、`0xfeel`、`212`、`215ul`
#### 浮点常量
与整型常量类似，可以使用`u`和`l`。浮点常量可以使用指数`e`或`E`表示，如`314159e-5`相当于`314159*( 10**-5 )`等于`3.14159`，`21E5`等于`2100000`
#### 字符常量
字符常量括在单引号中，如`'x'`可以存储在`char`类型的变量中，可以被强制类型转换成整数值
```C
char c = 'a';
int this_ascii = (int) c;  // 'c'的ASCII值97
```
字符常量的值可以是转义字符
#### const 与 \#difine的区别
`#define`进行简单的文本替换，在符号表中没有相关条目，在定义后的整个代码中有效
`const`定义的是一个具有类型的常量，仅在其作用域中有效



## C存储类
---
### auto
所有局部变量默认的存储类，只能用在函数内，在函数开始时被创建，函数结束时销毁。
在函数中，`int i`等同于`auto int i`
### register
定义存储在 **寄存器** 上而不是 **RAM** 中的局部变量。变量的最大尺寸等于寄存器大小，且不能使用`&`取地址（因为寄存器没有内存位置）
`register int  miles;`
频繁使用的变量使用`register`存储类可以提高程序运行速度。
编译器尽可能将此变量存储到寄存器中，不代表此变量一定被存储的寄存器。
### static
在程序的整个生命周期内存在的变量，在函数外定义的全局变量默认为`static`。

`static`仅初始化一次，当`static int count=10;`时，count被初始化。而后再次遇到`static int count=10;`，count的值不会被改变。
示例来源与[菜鸟教程](https://www.runoob.com/cprogramming/c-storage-classes.html)
```C
#include <stdio.h>
 
/* 函数声明 */
void func1(void);
 
static int count=10;        /* 全局变量 - static 是默认的 */
 
int main()
{
  while (count--) {
      func1();
  }
  return 0;
}
 
void func1(void)
{
/* 'thingy' 是 'func1' 的局部变量 - 只初始化一次
 * 每次调用函数 'func1' 'thingy' 值不会被重置。
 */                
  static int thingy=5;
  thingy++;
  printf(" thingy 为 %d ， count 为 %d\n", thingy, count);
}
/*
 thingy 为 6 ， count 为 9
 thingy 为 7 ， count 为 8
 thingy 为 8 ， count 为 7
 thingy 为 9 ， count 为 6
 thingy 为 10 ， count 为 5
 thingy 为 11 ， count 为 4
 thingy 为 12 ， count 为 3
 thingy 为 13 ， count 为 2
 thingy 为 14 ， count 为 1
 thingy 为 15 ， count 为 0
*/
```

### extern
**extern** 存储类用于定义在其他文件中声明的全局变量或函数，不会给变量分配任何空间。
如，当你在`a.c`定义一个全局变量或函数时，你可以在`b.c`中使用`extern`获取并使用它。而你需要把a.c和b.c联合编译`gcc a.c b.c`



## C运算符
---
### 算术运算符
假设变量 **A** 的值为 10，变量 **B** 的值为 20，则：

| 运算符 | 描述               | 实例            |
| --- | ---------------- | ------------- |
| +   | 把两个操作数相加         | A + B 将得到 30  |
| -   | 从第一个操作数中减去第二个操作数 | A - B 将得到 -10 |
| *   | 把两个操作数相乘         | A * B 将得到 200 |
| /   | 分子除以分母           | B / A 将得到 2   |
| %   | 取模运算符，整除后的余数     | B % A 将得到 0   |
| ++  | 自增运算符，整数值增加 1    | A++ 将得到 11    |
| --  | 自减运算符，整数值减少 1    | A-- 将得到 9     |

`a++`与`++a`的行为是不同的，
```C
int main(){
    int c;
    int a = 10;
    
    c = ++a;    // c 为 10, a 为 11。  先赋值后运算
    
    a = 10
    c = a++;    // c 为 11, a 为 11。  先运算后赋值
}  // 你可以加几个printf输出查看一下
```

### 关系运算符
假设变量 **A** 的值为 10，变量 **B** 的值为 20，则：

| 运算符 | 描述                              | 实例           |
| --- | ------------------------------- | ------------ |
| ==  | 检查两个操作数的值是否相等，如果相等则条件为真。        | (A == B) 为假。 |
| !=  | 检查两个操作数的值是否相等，如果不相等则条件为真。       | (A != B) 为真。 |
| >   | 检查左操作数的值是否大于右操作数的值，如果是则条件为真。    | (A > B) 为假。  |
| <   | 检查左操作数的值是否小于右操作数的值，如果是则条件为真。    | (A < B) 为真。  |
| >=  | 检查左操作数的值是否大于或等于右操作数的值，如果是则条件为真。 | (A >= B) 为假。 |
| <=  | 检查左操作数的值是否小于或等于右操作数的值，如果是则条件为真。 | (A <= B) 为真。 |

### 逻辑运算符
假设变量 **A** 的值为 1，变量 **B** 的值为 0，则：

| 运算符 | 描述                                        | 实例            |
| --- | ----------------------------------------- | ------------- |
| &&  | 称为逻辑与运算符。如果两个操作数都非零，则条件为真。                | (A && B) 为假。  |
| \|  | 称为逻辑或运算符。如果两个操作数中有任意一个非零，则条件为真。           | (A \| B) 为真。  |
| !   | 称为逻辑非运算符。用来逆转操作数的逻辑状态。如果条件为真则逻辑非运算符将使其为假。 | !(A && B) 为真。 |

### 位运算符
`&`、`|`、`^`、`~`、`<<`、`>>`，与Python一致，请查看[[Python基础语法#算数符号]]
### 赋值运算符

| 运算符 | 描述                               | 实例                        |
| --- | -------------------------------- | ------------------------- |
| =   | 简单的赋值运算符，把右边操作数的值赋给左边操作数         | C = A + B 将把 A + B 的值赋给 C |
| +=  | 加且赋值运算符，把右边操作数加上左边操作数的结果赋值给左边操作数 | C += A 相当于 C = C + A      |
| -=  | 减且赋值运算符，把左边操作数减去右边操作数的结果赋值给左边操作数 | C -= A 相当于 C = C - A      |
| *=  | 乘且赋值运算符，把右边操作数乘以左边操作数的结果赋值给左边操作数 | C *= A 相当于 C = C * A      |
| /=  | 除且赋值运算符，把左边操作数除以右边操作数的结果赋值给左边操作数 | C /= A 相当于 C = C / A      |
| %=  | 求模且赋值运算符，求两个操作数的模赋值给左边操作数        | C %= A 相当于 C = C % A      |
| <<= | 左移且赋值运算符                         | C <<= 2 等同于 C = C << 2    |
| >>= | 右移且赋值运算符                         | C >>= 2 等同于 C = C >> 2    |
| &=  | 按位与且赋值运算符                        | C &= 2 等同于 C = C & 2      |
| ^=  | 按位异或且赋值运算符                       | C ^= 2 等同于 C = C ^ 2      |
| \|= | 按位或且赋值运算符                        | C \|= 2 等同于 C = C \| 2    |
### 其它(sizeof、&、?:)

| 运算符      | 描述       | 实例                        |

## 条件语句
### if
```C
if ( a < 20 )
{
    printf("a 小于 20\n");
}

if ( a < 20 )
{
    printf("a 小于 20\n");
}
else
{
    printf("a 大于等于 20\n");
}

if ( a <= 20 )
{
    printf("a 小于等于 20\n");
}
else if ( a <= 40 )
{
    printf("20 < a <= 40\n");
}
else if ( a <= 60)
{
    printf("40 < a <= 60");
}
else
{
    printf("a 大于 60");
}
```
### switch
```C
#include <stdio.h>
 
int main ()
{
   /* 局部变量定义 */
   char grade = 'B';
 
   switch(grade)
   {
   case 'A' :    // 匹配'A'。case的后面必须是一个常量表达式
      printf("很棒！\n" );
      break;     // break是可选的，break退出swich阻止继续匹配
   case 'B' :    // 匹配到'B'时，穿透到C处输出“做得好”并结束swich
   case 'C' :    // 因为C switch-case的工作机制是跳转匹配，从匹配好的地方顺序
      printf("做得好\n" );    // 运行，直到break退出
      break;
   case 'D' :
      printf("您通过了\n" );
      break;
   case 'F' :
      printf("最好再试一下\n" );
      break;
   default :    // default是可选的，没有匹配则执行
      printf("无效的成绩\n" );
   }
   printf("您的成绩是 %c\n", grade );
 
   return 0;
}
```

## 循环语句
---
### while
```C
# include <stdio.h>
int main(){
    int a = 10;
    while ( a < 20 ){
        printf("a is %d", a);
        a++;
    }
    return 0;
}
```
### do-while
`do-while`在循环尾部检查条件，只是执行一次循环
```C
# include <stdio.h>
int main(){
    int a = 10;
    do{
        printf("a is %d", a);
        a++;
    }while (a < 20);
    return 0;
```
### for
```C
#include <stdio.h>
// for (初始化循环变量(可选，有分号即可); 条件; 更新循环变量)
int main(){
    for( int a = 10; a < 20; a = a + 1){
        printf("a is %d", a);
    }
    return 0;
}
```
### 循环控制语句(break、continue、goto)
`break`终止循环或switch语句
`continue`跳过当前循环中剩下的代码，进行下一次循环
`goto`**函数内**跳转到标签处。标签使用形如`lable:`定义，即字符后面跟一个冒号。
```C
label1:
// 省略
goto label1;
goto hello;
// 省略
hello;
```
***标签只能在函数内进行跳转***


## 函数
```
返回值类型  函数名  (参数类型  参数,  ...){
    函数主体
}
```
[[#基本结构]]
`函数声明`如`int add(int a, int b);`只声明存在一个函数，函数将在后面或其它文件中定义。如果要调用其他源文件中定义的函数的话（如[[#定义]]中联合编译而非[[#基本结构]]中的“#include”），函数声明是必须的。

函数的参数可以`传值调用`和`引用调用`。`传值调用`将参数的值复制给函数，函数的修改不会影响参数实际的值。而`引用调用`传递指向实参的指针，函数直接对实参本身进行操作
